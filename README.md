# Number Guessing Game

A beginner Python number guessing game where the player tries to guess a randomly generated number.

## Features

* Easy, Medium, and Hard difficulty levels
* Maximum of 7 attempts
* Tells the player if the guess is too high or too low
* Gives a "Very Close" hint when the guess is within 5
* Handles invalid input
* Option to play again

## How to Run

1. Make sure Python is installed.
2. Open the project in VS Code.
3. Run `main.py`.
4. Choose a difficulty level.
5. Try to guess the secret number within 7 attempts.
